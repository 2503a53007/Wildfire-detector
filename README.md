# Wildfire-detector
Project Description

Wildfire Detector is a data processing project that cleans and prepares satellite-based fire detection data for further analysis.

Technologies Used

- Python
- Pandas
- CSV Dataset
- GitHub

Data Cleaning Operations

1. Loading the original dataset.
2. Checking missing values.
3. Removing duplicate records.
4. Handling missing values.
5. Converting data types.
6. Validating latitude and longitude.
7. Removing invalid records.
8. Combining date and time columns.
9. Saving the cleaned dataset.

Project Files

- "cleaning.py" – Python code for data cleaning.
- Original Dataset – Raw fire detection data.
- Cleaned Dataset – Processed fire detection data.
